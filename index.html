    Đoạn phim Friends chính thức trên YouTube

    Lấy từ kênh YouTube chính thức của Friends, mỗi đoạn 2–9 phút.
    Nạp phụ đề cho nhiều đoạn một lúc

    Tải phụ đề ở DownSub cho các đoạn bạn muốn học, rồi bấm nút bên cạnh và chọn tất cả file .srt trong thư mục Tải xuống (Downloads). Mẹo: bấm vào một file, rồi bấm Ctrl + A để chọn hết. Trang tự nhận ra file nào thuộc đoạn nào.

    Chuyển phụ đề và sổ từ sang máy khác

    Tự đồng bộ giữa máy tính và điện thoại Chưa kết nối

    Kết nối một lần trên mỗi máy. Sau đó phụ đề, sổ từ và chỗ đang xem tự lưu vào kho riêng tư luyen-nghe-du-lieu trên GitHub của bạn, máy nào mở trang cũng có.

    1. Bấm Mở trang tạo mã ↗ (cần đăng nhập GitHub).
    2. Ô Token name: gõ luyen-nghe. Ô Expiration: chọn No expiration hoặc thời hạn dài nhất.
    3. Mục Repository access: chọn Only select repositories, rồi chọn luyen-nghe-du-lieu.
    4. Mục Permissions: bấm Add permissions, chọn Contents, đổi thành Read and write.
    5. Bấm Generate token, bấm biểu tượng sao chép cạnh mã, rồi dán vào ô dưới đây và bấm Kết nối.

    Trên điện thoại: mở trang này và dán cùng mã đó (gửi mã cho chính bạn qua Zalo để sao chép). Đừng gửi mã cho người khác.

    Không muốn kết nối? Vẫn có thể chuyển bằng file: bấm “Tạo file sao lưu” trên máy tính, gửi file sang điện thoại (Zalo, Messenger, Google Drive), rồi trên điện thoại bấm “Khôi phục từ file”.

    Kho phim của bạn

    Chưa mở phim nào. Đang dùng bài mẫu.
    Kéo thả file video (.mp4) và phụ đề (.srt) vào đây, hoặc bấm “Mở phim và phụ đề” ở trên. Chọn được nhiều tập một lúc.

    Phim của bạn chỉ mở ngay trên máy bạn, không bị tải lên mạng. Vì vậy mỗi lần mở lại trang, bạn chọn lại file. Trang vẫn nhớ bạn đã xem tới đâu và các từ đã lưu.

    Cách học bằng trang này

    1. Chuẩn bị file

    • File phim, ví dụ Friends.S01E01.mp4.
    • Phụ đề tiếng Anh: Friends.S01E01.en.srt
    • Phụ đề tiếng Việt (không bắt buộc): Friends.S01E01.vi.srt

    Trang tự ghép các file cùng tập nhờ mã S01E01 trong tên. File phụ đề song ngữ (một file có cả Anh lẫn Việt) cũng dùng được.

    2. Học theo 4 bước

    1. Xem với phụ đề Anh + Việt để hiểu nội dung.
    2. Bật “Tự dừng sau mỗi câu”, nghe lại câu khó, bấm từ lạ để tra.
    3. Đổi phụ đề sang “Ẩn”, xem lại và cố nghe hiểu.
    4. Sang thẻ “Chép chính tả” để gõ lại từng câu.

    3. Lấy phụ đề ở đâu

    Phụ đề Friends và nhiều phim khác có miễn phí trên OpenSubtitles (chọn ngôn ngữ English và Vietnamese, tải file .srt). Hãy chọn bản phụ đề khớp với bản phim bạn có để chữ chạy đúng lúc.
